BIM Mission ControlISO 19650 · shared folder edition
How it works: sign in (name + email), Connect JSON to MC_data.json in this folder for auto-save (Chrome/Edge), or use Load/Save manually. Every change is stored in the Change log with your name and date — immutable.

00Active projects

Every project the team manages. The BIM Manager sees them all on entry.
Pick a project in the Dashboard, or create a new one.

01Project identity

Contract / quote, client and base data. Editable — every change is logged.

02Team & disciplines

ISO 19650 roles and disciplines — with the responsible person and their email. Disciplines listed here drive which CDE folders are created.

03Client file register

What the client must deliver, when they promised it, when it arrived, revision, and when we updated it in the project.

04Client / Appointing Party (ISO 19650)

Client-side inputs that feed the EIR: appointing party and information requirements (OIR / PIR / AIR) + brand standards. Legal documents (deeds, licenses, taxes, permits) live in the Legal tab.

05Milestones & delivery dates

Data drops for this project — add or remove as many as the project needs. These dates feed the EIR, BEP, MIDP/TIDP and the process maps.
Planned = the target deadline for each drop; it must go in order (M1 earliest → M5 latest) — this is what the Schedule tab uses. Actual = when it was really delivered; leave it empty until it happens. Cells that break the order turn amber, empty Planned dates turn red.
Example — Planned: M1 2026-03-02 · M2 2026-04-15 · M3 2026-06-01 · M4 2026-07-15 · M5 2026-09-01  |  Actual: fill each one only after that drop is delivered.

06Create ISO 19650 folders & documents

Generates the full project folder tree on your disk — no Claude. Chrome/Edge. Only the disciplines listed in section 02 get CDE folders (e.g. if structural is not contracted, no structural folders are created).
Template library: not linked
Creates the folder tree, then asks whether to copy the project documents from your _BaseLine Documents library. Pick the PARENT folder (a folder with the project name is created inside it).
Copy documents from _BaseLine Documents without recreating folders. Pick the project ROOT folder. You'll be asked once for your _BaseLine Documents folder (remembered afterwards).

05Change log — who changed what

Append-only record. Not editable. Every row keeps its author and date.
Immutable — the app only appends rows, it never edits previous ones.

06Users & access

Who has access to the MC (designers / staff + email). Someone is registered automatically on sign-in; their Change-log entries use the same name and email. You can also pre-register people.

06bAccess history

Every time someone enters and signs in it is logged here, with date. Not editable.
Immutable — rows are only appended.

07bContract & legal entities

Feeds the Services Agreement and BIM Protocol: legal entities, registration numbers, fee and applicable law.

07cLegal document register

Deeds, licenses, taxes and permits the client provides — with reference, status and date.

Estimated time each discipline needs up to its milestone deliveries. Deadlines are the project milestones (section 05); drag a bar to set a discipline's estimated dates within them. Charts update live — this data is ready to export to ClickUp later.
